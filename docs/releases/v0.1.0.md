# Belmivo v0.1.0

A personal self-hosted bridge from an approved iMessage sender to Codex on a Mac. Apache-2.0 licensed.

Included: authenticated provider webhooks, sender/destination checks, durable task mapping and deduplication, desktop and app-server backends, task commands, cancellation, supported attachment handling, optional outbound relay, and macOS login-service helpers.

Install from reviewed source with Node 24+, configure a working provider webhook/reply entitlement, and verify a foreground phone exchange before enabling a login service. See [setup](../CONFIGURATION.md) and [operations](../OPERATIONS.md).

The Mac must remain awake, online and logged in. Desktop IPC is private and version-sensitive; app updates may require an adapter update. The alternative backend has different tools. Full Access is not a sandbox. Unknown execution or delivery is held for inspection, and cancellation does not undo completed effects.

The source archive contains no credentials, live journals, dependencies or development Git history. Build before running. No hosted signup or automatic number provisioning is included. Provider acceptance is not proof of physical handset receipt; validate the needed behavior on your installation.
