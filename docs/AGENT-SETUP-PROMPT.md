# Set up with an agent

Paste the following into your coding agent after reviewing the authorization it grants. Adjust the budget and requested scope to your needs; the text is not permission until you choose to send it.

```text
Set up Belmivo from https://github.com/pkyanam/Belmivo at v0.1.0. Read AGENTS.md, README.md, docs/CONFIGURATION.md and docs/SECURITY.md.

Reuse existing configuration, provider enrollment, task bindings, webhooks and services. Prefer legitimate free evaluation. Do not purchase anything, contact support, duplicate accounts or send messages to anyone else. Ask for missing account or phone verification privately; never put credentials in chat, Git or shell arguments.

I authorize a dedicated Full Access task, only my approved sender, configuration of my chosen free provider entitlement, a test request/reply with my phone, and local bridge/tunnel login services. Explain Full Access before enabling it if I have not already selected it.

Build using --no-setup first. Set up the selected connection, register the authenticated webhook, then run the printed setup command with its selected runtime. Open the dedicated desktop task. Verify one real foreground exchange before an idle, graceful transition to the login service. Preserve uncertain work and never interrupt unrelated processes. Report what works and what remains unverified.
```

A named tunnel needs an installed `cloudflared`, an authorized account and a domain you control. An outbound relay needs an existing enrollment or a separately authorized self-operated deployment. Neither the prompt nor installer supplies provider credits or a number.
